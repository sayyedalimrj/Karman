# data/incoming/taksa/pdf

Official **provenance** PDFs. Analyzed by `taksa:pdf:audit` for metadata
(size/checksum/page count/title) and filename classification. **No OCR, no
numeric extraction, no automatic official import.** Raw files are
ingestion/analyze inputs only; they are git-ignored and never read by the
website (the UI reads PostgreSQL metadata). See `../README.md`.
