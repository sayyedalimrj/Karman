## منابعی که فعلاً نباید وارد ریپو یا تحلیل اجرایی شوند

- `EXE`, `DLL`, `OCX`, `SYS`, `MSI`, ابزارهای ریموت، قفل سخت‌افزاری و Tiny/Lock.
- فایل کامل `Faragamara_Taksa.DB` با حجم حدود ۱GB؛ فقط در صورت نیاز و روی سیستم خودت برای schema/داده نمونه باز شود.
- `Main/help_taksa.chm` چون حدود ۴۷MB است؛ فعلاً با فایل‌های سبک‌تر و PDFها جلو می‌رویم.
- فایل‌های ویدئویی یا اجرایی آموزشی؛ فعلاً فقط نام آن‌ها برای workflow کافی است.

## تصمیم‌های ثبت‌شده برای ادامه مسیر

1. اولویت اول بعدی، **کاتالوگ گزارش‌ها** است؛ چون خروجی‌های واقعی محصول را مشخص می‌کند.
2. بعد از گزارش‌ها، سراغ **DB/myscr.sql + ScriptConst.sql + ScriptXML.sql** می‌رویم تا جدول‌ها، روابط و مسیر import/export روشن شود.
3. `gws.ini` و `tx_tips*.txt` را برای نقشه فرم‌ها و اصطلاحات UI نگه می‌داریم.
4. PDFهای `Lc` و `Shkh` و اسناد `Main_Docs_Selected` برای موتور تعدیل و ضرایب در اولویت بالاست.
5. نسخه وب قرار نیست raw viewer تکسا باشد؛ ابتدا raw compatibility layer، بعد مدل استاندارد وب.
